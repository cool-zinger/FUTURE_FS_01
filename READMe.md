# Kaustav Nandi — Personal Portfolio

A modern full-stack personal portfolio built with:

- React
- Vite
- Tailwind CSS
- Node.js
- Express.js
- MySQL
- Nodemailer

## Features

- Responsive portfolio
- SEO metadata
- Hero section
- About section
- Skills
- Project showcase
- Resume section
- Achievement section
- Contact form
- Express REST API
- MySQL contact storage
- Nodemailer email notification
- Mobile navigation
- Modern dark UI
- GitHub and Live Demo placeholders
